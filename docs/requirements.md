# 프로젝트 요구 사항

# 기수/팀 별 루트 URL

API_BASE_URL

```
https://sp-taskify-api.vercel.app/22-3/
```

### 1) 공통

- 제시된 폰트와 컬러 시스템을 설정하세요.
- 재사용성을 위해 공용 컴포넌트를 만들어 주세요.
- 반응형 웹 디자인을 준수하세요.
- 사용 할 이미지 파일 이름은 영어로 되어있어야 합니다.

### 2) 상단 네비게이션바, 사이드바 구현하기

- 상단 네비게이션바 구현하기
  - 오른쪽 이름을 누르면 드롭다운으로 '로그아웃' 버튼, '내 정보' 버튼, '내 대시보드' 버튼이 보이도록 하세요.
  - '로그아웃' 버튼을 클릭하면 `/` 페이지로 이동하게 하세요.
  - '내 정보' 버튼을 클릭하면 `/mypage` 페이지로 이동하게 하세요.
  - '내 대시보드' 버튼을 클릭하면 `/mydashboard` 페이지로 이동하게 하세요.
- 사이드바 구현하기
  - 각 대시보드를 클릭하면 `/dashboard/{dashboardid}` 페이지로 이동하게 하세요.
  - 사이드바 대시보드는 페이지네이션으로 구현하세요 (무한 스크롤은 사용하지 마세요).
  - '+' 버튼을 클릭하면 대시보드 생성 모달이 나타나도록 하세요.

### 3) 로그인, 회원가입 페이지 구현하기

- 로그인 페이지 구현하기(`/login`)
  - '로고 버튼'을 클릭하면 `/` 페이지로 이동하게 하세요.
  - '회원가입하기' 버튼을 클릭하면 `/signup` 페이지로 이동하게 하세요.
  - 유효한 이메일과 비밀번호를 입력하고 '로그인' 버튼을 클릭하면 `/mydashboard` 페이지로 이동하게 하세요.
  - 로그인 페이지에는 네비게이션바가 없도록 하세요.
  - 비밀번호가 틀릴 경우 “비밀번호가 일치하지 않습니다.”라는 경고 창을 보여주세요.
  - 눈 모양 아이콘을 클릭하면 비밀번호를 숨기거나 나타내도록 하세요.
  - 이메일 input에서 focus out 시, 값이 이메일 형식이 아닐 경우 빨간색 테두리와 아래에 “이메일 형식으로 작성해 주세요.”라는 빨간색 에러 메시지를 보이게 하세요.
  - 비밀번호 input에서 focus out 시, 비밀번호 길이가 8자 미만일 경우 빨간색 테두리와 아래에 “8자 이상 작성해 주세요.”라는 빨간색 에러 메시지를 보이게 하세요.
  - 로그인 성공 시 엑세스 토큰을 발급하세요.
- 회원가입 페이지 구현하기(`/signup`)
  - '로고 버튼'을 클릭하면 `/` 페이지로 이동하게 하세요.
  - '로그인하기' 버튼을 클릭하면 `/login` 페이지로 이동하게 하세요.
  - 닉네임 input에서 focus out 시, 값이 열 자 이하가 아닐 경우 빨간색 테두리와 아래에 “열 자 이하로 작성해주세요.”라는 빨간색 에러 메시지를 보이게 하세요.
  - 이메일 input에서 focus out 시, 값이 이메일 형식이 아닐 경우 빨간색 테두리와 아래에 “이메일 형식으로 작성해 주세요.”라는 빨간색 에러 메시지를 보이게 하세요.
  - 비밀번호 input에서 focus out 시, 비밀번호 길이가 8자 미만일 경우 빨간색 테두리와 아래에 “8자 이상 입력해주세요.”라는 빨간색 에러 메시지를 보이게 하세요.
  - 비밀번호 확인 input에서 focus out 시, 비밀번호 input 값과 비밀번호 확인 input 값이 다를 경우 빨간색 테두리와 아래에 “비밀번호가 일치하지 않습니다.”라는 빨간색 에러 메시지를 보이게 하세요.
  - 모든 input 창이 채워지고 에러 메시지가 없는 상태에서 이용약관에 체크가 되면 '가입하기' 버튼이 활성화되도록 하세요.
  - 중복되는 이메일로 회원가입 시도 시 '이미 사용중인 이메일입니다'라는 모달 창이 나타나게 하세요.
  - 활성화된 '가입하기' 버튼을 클릭하면 “가입이 완료되었습니다”라는 alert 창을 보여주고 `/login` 페이지로 이동하게 하세요.

### 4) 메인 랜딩 페이지 구현하기(`/`)

- '로고 버튼'을 클릭하면 `/` 페이지로 이동하게 하세요.
- '로그인' 버튼을 클릭하면 `/login` 페이지로 이동하게 하세요.
- '회원가입' 버튼을 클릭하면 `/signup` 페이지로 이동하게 하세요.
- 로그인이 되어 있으면 `/dashboard/{첫 번째 dashboardid}`로 이동하게 하세요.

### 5) 나의 대시보드 페이지 구현하기(`/mydashboard`)

- '로고' 버튼을 클릭하면 `/` 페이지로 이동하게 하세요.
- 내가 만든 대시보드 끝에는 👑 이 붙도록 하세요.
- 내 대시보드는 페이지네이션으로 구현하세요.
- 초대받은 대시보드는 무한 스크롤로 구현하세요.
- 내 대시보드를 각각 클릭하면 해당 대시보드 페이지로 `/dashboard/{dashboardid}`로 이동하게 하세요.
- '+' 버튼을 클릭하면 대시보드 생성 모달이 나타나게 하세요.
- 초대받은 대시보드가 없으면 “아직 초대받은 대시보드가 없어요”라는 문구를 보여주도록 하세요.
- 초대받은 대시보드에서 이름(title)으로 검색이 가능하도록 하세요 (키워드가 이름에 일부라도 포함되면 모두 검색되도록 하세요).
- 초대받은 대시보드에서 '수락' 버튼을 누르면 대시보드가 추가되도록 하세요
- 초대받은 대시보드에서 '거절' 버튼을 누르면 해당 대시보드는 삭제되도록 하세요.

### 6) 대시보드 상세 페이지 구현하기(`/dashboard/{dashboardid}`)

- 네비게이션 상단 오른쪽에 초대받은 멤버가 보이도록 하세요.
- 각 칼럼의 카드들은 무한 스크롤로 이어지도록 하세요.
- 내가 만든 보드에는 상단에 '관리' 버튼이 보이도록 하세요.
- '관리' 버튼을 클릭하면 `/dashboard/{dashboardid}/edit`로 이동하게 하세요.
- '초대하기' 버튼을 클릭하면 초대하기 모달창이 나타나도록 하세요.
- 내가 만든 대시보드 이름 우측에는 왕관 모양이 보이도록 하세요.
- 각 컬럼 오른쪽에 해당 카드 개수가 보이도록 하세요.
- '새로운 컬럼 추가하기' 버튼을 클릭하면 컬럼 추가하기 모달이 나타나도록 하세요.
- 각 컬럼의 '+' 버튼을 클릭하면 해당 컬럼 할 일 생성 모달이 나타나도록 하세요.
- 각 컬럼의 '톱니바퀴' 버튼을 클릭하면 컬럼 수정 모달이 나타나도록 하세요.
- 생성된 할 일 카드를 클릭하면 해당 카드 상세 모달이 나타나도록 하세요.

### 7) 대시보드 생성, 수정 구현하기

- 대시보드 생성 모달 구현하기
  - '+' 버튼을 클릭하면 대시보드 생성 모달이 나타나도록 하세요.
  - 대시보드 생성 모달에서 대시보드 이름과 색을 선택해야 '생성' 버튼이 활성화되도록 하세요.
  - 대시보드 '생성' 버튼을 클릭하면 대시보드가 생성되고 `/dashboard/{dashboardid}`로 이동하게 하세요.
- 대시보드 수정 구현하기(`/dashboard/{dashboardid}/edit`)
  - 대시보드 이름이나 색을 바꾸고 '변경' 버튼을 클릭하면 대시보드가 수정되도록 하세요.
  - '돌아가기' 버튼을 클릭하면 `/dashboard/{dashboardid}`로 이동하게 하세요.
  - 대시보드 각 구성원 오른쪽에 있는 '삭제' 버튼을 클릭하면 구성원이 삭제되도록 하세요.
  - 구성원 리스트는 페이지네이션으로 구현하세요.
  - 초대 내역 리스트는 페이지네이션으로 구현하세요.
  - '초대하기' 버튼을 클릭하면 초대하기 모달창이 나타나도록 하세요.
  - 초대 내역 각 오른쪽의 '취소' 버튼을 클릭하면 해당 초대가 취소되도록 하세요.

### 8) 할 일 카드 상세 모달 구현하기(`/dashboard/{dashboardid}`)

- 할 일 카드 상세 모달 구현하기
  - 만들어진 카드 정보를 보여주도록 하세요.
  - 댓글 input에 값이 비어있으면 '입력' 버튼이 비활성화되도록 하세요.
  - 댓글 input에 값을 입력하고 '입력' 버튼을 클릭하면 댓글이 남겨지도록 하세요.
  - 댓글은 무한 스크롤로 이어지도록 하세요.
  - 내가 남긴 댓글에 '수정' 버튼을 클릭하면 내용을 수정할 수 있도록 하세요.
  - 내가 남긴 댓글에 '삭제' 버튼을 클릭하면 내용을 삭제할 수 있도록 하세요.
  - 오른쪽 상단 케밥을 클릭하면 드롭다운으로 수정하기, 삭제하기를 고를 수 있도록 하세요.
  - '수정하기' 버튼을 클릭하면 할 일 수정 모달이 나타나도록 하세요.
  - '삭제하기' 버튼을 클릭하면 해당 카드가 삭제되도록 하세요.
- 할 일 카드 수정 모달 구현하기
  - 만들어진 카드 정보로 input이 기본값으로 채워지도록 하세요.
  - 값이 하나라도 바뀌면 '수정' 버튼이 활성화되도록 하세요.
  - '수정' 버튼을 클릭하면 해당 카드에 수정된 정보가 반영되도록 하세요.
  - 마감일은 날짜 입력 라이브러리를 사용해서 입력을 받도록 하세요.
- 할 일 카드 생성 모달 구현하기
  - 모든 input이 채워지면 '생성' 버튼이 활성화되도록 하세요.
  - 담당자는 드롭다운으로 초대받은 인원만 선택할 수 있도록 하세요.
  - 이미지는 최대 1개만 업로드할 수 있도록 하세요.
  - 카드 생성에 사용되는 이미지는 반드시 **카드 이미지 업로드** api를 사용해주세요 ( 프로필 이미지 업로드 api X)
  - 태그 색상은 랜덤으로 선택되도록 하세요.
  - '생성' 버튼을 클릭하면 해당 컬럼 하단에 할 일 카드가 생기도록 하세요.
  - 날짜 입력은 날짜 입력 라이브러리를 사용해서 입력받도록 하세요.

### 9) 컬럼 추가, 관리 모달 구현하기(`/dashboard/{dashboardid}`)

- 컬럼 추가 모달 구현하기
  - 이름 input에 입력값이 없으면 '생성' 버튼은 비활성화되도록 하세요.
  - 컬럼 이름이 중복되면 “중복된 컬럼 이름입니다”라는 경고창을 보여주도록 하세요.
  - 활성화된 '생성' 버튼을 클릭하면 컬럼이 추가되도록 하세요.
  - 칼럼은 최대 10개까지 생성이 가능하도록 하세요.
  - 칼럼은 스크롤로 이어지도록 하세요.
- 컬럼 관리 모달 구현하기
  - '삭제하기' 버튼을 클릭하면 “컬럼의 모든 카드가 삭제됩니다”라는 경고창을 보여주도록 하세요.
  - '예' 버튼을 클릭하면 해당 컬럼의 모든 할 일 카드들이 삭제되도록 하세요.
  - 수정할 이름을 입력하고 '변경' 버튼을 클릭하면 컬럼 이름이 수정되도록 하세요.

### 10) 초대하기 모달 구현하기(`/dashboard/{dashboardid}/edit`)

- 유효한 이메일을 입력하고 '초대' 버튼을 클릭하면 해당 이메일을 가진 유저에게 초대가 가도록 하세요.
- 중복된 이메일로 초대를 보낼 수 있도록 하세요.
- 값을 입력하지 않으면 '초대' 버튼은 비활성화되도록 하세요.

### 11) 계정 관리 구현하기(`/mypage`)

- '+' 버튼을 클릭하면 이미지를 업로드할 수 있도록 하세요.
- 이메일은 수정할 수 없도록 하세요.
- 닉네임 또는 이미지를 바꾸고 '저장' 버튼을 클릭하면 정보가 수정되도록 하세요.
- 새 비밀번호 확인 input에서 focus out 시, 새 비밀번호 input 값과 다를 경우 빨간색 테두리와 아래에 “비밀번호가 일치하지 않습니다.”라는 빨간색 에러 메시지를 보이게 하세요.
- 모든 input이 채워지면 '변경' 버튼이 활성화되도록 하세요.
- '변경' 버튼을 클릭했을 때 현재 비밀번호 값이 틀리면 “현재 비밀번호가 틀립니다”라는 경고창이 나타나도록 하세요.
- 정확한 현재 비밀번호 값을 입력하고 '변경' 버튼을 클릭하면 비밀번호가 변경되도록 하세요
