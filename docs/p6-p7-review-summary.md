# Taskify P6~P7 작업 요약

이번 진행에서는 **대시보드 수정 페이지 구현**과 **대시보드 상세의 컬럼/카드/댓글 CRUD 핵심 흐름**을 이어서 반영했습니다.

## 1. 대시보드 수정 페이지

- `/dashboard/:dashboardId/edit` 실제 화면 구현
- 대시보드 제목/색상 수정 API 연동
- owner 전용 접근 처리
- 구성원 목록 조회 + 페이지네이션
- 구성원 삭제 처리
- 초대 내역 조회 + 페이지네이션
- 초대 취소 처리
- 수정 페이지에서도 초대 모달 재사용

## 2. 컬럼 관리

- 컬럼 생성 API 추가 및 생성 모달 연결
- 컬럼 이름 중복 체크
- 컬럼 최대 10개 제한 처리
- 컬럼 수정 API 추가 및 관리 모달 연결
- 컬럼 삭제 API 추가 및 경고 모달 연결

## 3. 카드 관리

- 카드 생성 API 추가 및 생성 모달 연결
- 카드 수정 API 추가 및 수정 모달 연결
- 카드 삭제 API 추가
- 카드 이미지 업로드 API 추가
- 카드 컬럼 변경을 수정 모달에서 선택 가능하도록 구현

## 4. 댓글 관리

- 댓글 수정 API 추가
- 댓글 삭제 API 추가
- 카드 상세 모달에서 본인 댓글 수정/삭제 가능하도록 구현

## 5. 카드 정렬

- 같은 컬럼 내부에서 카드 순서를 위/아래 버튼으로 조정 가능
- 현재 정렬은 API 필드가 없어 로컬 상태 기준으로 유지

## 6. 공통/재사용 구조

- 대시보드 생성 모달을 별도 컴포넌트로 분리
- 초대 모달을 별도 컴포넌트로 분리
- 카드 폼 모달을 재사용 가능하게 분리
- 컬럼 생성/관리 모달을 별도 컴포넌트로 분리

## 7. 검증

- `npm run lint` 통과
- `npm run build` 통과

## 8. 아직 남은 핵심 작업

- 카드 이동을 더 직관적인 UX로 개선
- 카드/컬럼 변경 후 세부 UX 다듬기
- 마이페이지 실제 구현
- 비밀번호 변경 / 프로필 수정 / 이미지 업로드
- 최종 QA 및 반응형 디테일 보정
