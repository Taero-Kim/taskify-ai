## 2. 발견 이슈 목록

### QA-001. MyDashboard 초대 목록 API 무한 호출

- 증상: `/mydashboard` 진입 시 `/{teamId}/invitations` 요청이 반복적으로 발생
- 원인: `fetchInvitations`가 자신이 갱신하는 state에 의존하여 effect 재실행 루프가 발생
- 조치: cursor/hasMore/fetching 상태를 `ref`로 분리해 callback 안정화
- 상태: **해결 완료**
- 참고 문서: `docs/mydashboard-invitations-loop-fix-report.md`

### QA-002. 대시보드 생성 모달에서 Router Context 오류

- 증상: `대시보드 생성` 클릭 시 `useNavigate() may be used only in the context of a <Router> component.` 발생
- 원인: `ModalProvider`가 `RouterProvider` 바깥에 위치해 modal content가 router context를 받지 못함
- 조치: `AppProviders`를 Router 내부로 이동
- 상태: **해결 완료**
- 참고 문서: `docs/modal-router-context-fix-report.md`

### QA-003. 대시보드 카드 내부 중첩 버튼 구조

- 증상: 카드 전체가 버튼인데 내부에 정렬 버튼(↑/↓)이 추가되면 중첩 button 구조가 생길 가능성 확인
- 영향: DOM 구조가 비정상적이어서 클릭 이벤트 충돌 및 접근성 문제 가능
- 조치: 카드 레이아웃을 분리해 상호작용 버튼과 카드 오픈 버튼이 충돌하지 않도록 정리
- 상태: **해결 완료**

### QA-004. 마이페이지에 실제 기능과 무관한 페이지네이션 UI 노출

- 증상: `/mypage` 상단에 사이드바 대시보드용 페이지네이션 숫자와 버튼이 노출됨
- 원인: 이전 단계 구현 중 사이드바 대시보드 조회 상태가 마이페이지에 남아 있었음
- 조치: 불필요한 대시보드 조회/페이지네이션 상태 제거
- 상태: **해결 완료**

### QA-005. 카드 정렬 영속성 부족

- 증상: 같은 컬럼 내부 카드 위/아래 이동은 가능하지만 새로고침 시 순서가 유지되지 않음
- 원인: API에 정렬 필드가 없어서 현재는 로컬 상태로만 순서를 관리함
- 조치: 현재는 로컬 상태 유지로 동작하게 두고, 제한 사항으로 기록
- 상태: **오픈(제약 사항)**
- 비고: 서버 지원 또는 별도 저장 전략이 필요
