# Taskify

Taskify는 일정 관리와 공유 기능을 제공하는 React + TypeScript 기반 웹 애플리케이션입니다.

## 실행 방법

```bash
npm install
npm run dev
```

## 주요 스크립트

```bash
npm run dev
npm run lint
npm run build
npm run preview
npm run format
```

## 현재 진행 상태

- P0 완료: 라우트 / API 매핑 / 부트스트랩 기준 정리
- P1 완료: 프로젝트 초기화, Tailwind, ESLint, Prettier, Husky, 기본 라우트 구성
- P2 이후 예정: fetch, auth context, route guard, 공통 UI 구현
